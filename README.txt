NIGHT FM + ElevenLabs

1. Cài Node.js 18+.
2. Mở terminal trong thư mục này.
3. Chạy:
   npm install
4. Copy .env.example thành .env
5. Mở .env và đặt:
   ELEVENLABS_API_KEY=API_KEY_CUA_BAN
6. Chạy:
   npm start
7. Mở:
   http://localhost:3000
